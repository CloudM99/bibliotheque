Bibliothèque

Bienvenue dans le projet Bibliothèque ! Ce document vous guidera à travers l'installation, la configuration et le lancement de l'application.
Prérequis

Avant de commencer, assurez-vous d'avoir les éléments suivants installés sur votre machine :

    Flutter SDK : Vérifiez avec flutter --version
    Dart SDK : Inclus avec Flutter
    Android Studio (pour le développement Android)
    Xcode (pour le développement iOS)
    Un émulateur Android ou un appareil physique (pour tester l'application Android)
    Un simulateur iOS ou un appareil physique (pour tester l'application iOS)

Installation
Cloner le projet :

    Cloner le projet : git clone https://github.com/CloudM99/bibliotheque.git cd bibliotheque
    

Installer les dépendances :

    flutter pub get

Configuration

    Configurer les variables d'environnement :
        Assurez-vous que votre environnement Flutter est correctement configuré. Vous pouvez vérifier cela en exécutant :

        flutter doctor

        Suivez les instructions pour résoudre les problèmes éventuels.

    Configurer les plateformes :
        Pour Android : Assurez-vous que votre environnement Android est configuré correctement.
        Pour iOS : Assurez-vous que votre environnement iOS est configuré correctement.

Lancement

    Démarrer l'application sur Android :

flutter run

Démarrer l'application sur iOS :

    flutter run
    

Accéder à l'application :
        L'application devrait se lancer sur l'émulateur ou l'appareil physique connecté.

Documentation

Pour plus de détails sur le code et les fonctionnalités de l'application, consultez la documentation interne : doc/index.html
